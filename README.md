
# ⛺ KemMY – Cari Campsite Malaysia

A web app to help Malaysians discover, explore, and contact campsite owners across Malaysia.

---

## 🌿 Features

- **Explore Campsites** – Browse 10 campsites across Malaysia with photos, ratings, and details
- **Search & Filter** – Search by name or location, filter by type (Jungle, Beach, Glamping, etc.)
- **Campsite Details** – View facilities, rules, capacity, pricing, and best-for categories
- **Contact Owner** – Call or WhatsApp campsite owners directly from the app
- **Google Maps** – Open any campsite location in Google Maps with one click
- **Reviews** – Read community reviews and submit your own rating
- **Map View** – See all campsites listed with coordinates

---

## 🚀 How to Use

1. Download or clone this repository
2. Open `index.html` in any web browser
3. No installation or internet connection required *(except for campsite photos)*
